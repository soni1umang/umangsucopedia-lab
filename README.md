# Ucopedia Lab

**The Curious Laboratory** — an experimental redesign of Umang's Ucopedia.

This is a separate playground based on the stable `umangsucopedia-v2` baseline. The stable v2 repository is not modified by this project.

## Direction

- **Read** — essays, books and questions
- **Research** — academia, publications and research work
- **Make** — workbench, photography and paints
- **Now** — a living snapshot of what is occupying my brain

The design language mixes an editorial notebook with a quiet scientific laboratory: paper, measurements, signals, maps, field notes and subtle motion.

The site is built with React + Vite + TanStack Router and uses Supabase for content/auth/storage.
